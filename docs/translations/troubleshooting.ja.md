# トラブル対処

症状に合う項目から確認してください。通常の操作は[使い方](user-guide.ja.md)で説明しています。このページでは問題を確認し、解消しない場合に報告用の情報を集める手順を説明します。

## 基本の確認

- YouTube プレイヤーの全画面ボタンを使ってください。シアターモードやブラウザのウィンドウ全体を全画面にする操作とは異なります。
- ブラウザのツールバーから拡張機能のポップアップを開き、有効になっていることを確認してください。
- ライブ配信、またはチャットリプレイを再生できるアーカイブを使ってください。通常の動画、チャットが無効な配信、リプレイを利用できないアーカイブでは、チャットを重ねて表示しません。

拡張機能用のアカウントは必要ありません。ライブ配信中の投稿に必要なログインは、YouTube の通常のルールに従います。

## チャットの切り替えボタンが表示されない

プレイヤーの右下にある切り替えボタンは、その動画で YouTube がチャットを提供している場合にだけ表示されます。

1. ライブ配信、またはチャットリプレイがあるアーカイブを開きます。通常の動画にはチャットがないため、切り替えボタンは表示されません。
2. フルスクリーンにします。切り替えボタンはフルスクリーンのプレイヤーの操作ボタン内に表示されます。
3. チャットがあり、拡張機能も有効なのに切り替えボタンが表示されない場合は、フルスクリーンを解除し、ページを一度再読み込みしてから、もう一度フルスクリーンにします。

## 切り替えボタンはあるがチャットが空のまま

アーカイブのリプレイは、再生できるまで少し待つ場合があります。フルスクリーンを解除して YouTube 本来のチャットリプレイが読み込まれるかを確認し、もう一度フルスクリーンにしてください。

YouTube のチャットが利用できるのに重ねたチャットが空のままなら、動画の種類、再現手順、後述の診断レポートを添えて報告してください。YouTube 本来のチャットが利用できるのに空のままになる問題と、動画にチャットがない状態は別です。

## Opera で切り替えボタンやチャットが表示されない

1. `opera://extensions` を開きます。
2. 拡張機能が有効で、`youtube.com` へのアクセスが許可されていることを確認します。
3. ライブ配信、またはチャットリプレイがあるアーカイブを再読み込みして、フルスクリーンにします。

Chrome と同じく、切り替えボタンはその動画でチャットが利用できる場合にだけ表示されます。

## 表示がおかしい・操作に反応しない

1. 問題が起きている YouTube のタブを選択したまま、ブラウザのツールバーから拡張機能のポップアップを開きます。「診断をコピー」が使える場合は、再試行する前にレポートをコピーします。
2. 「チャット表示を再試行」を選び、次に「状態を確認」を選んで、動画の表示も確認します。再試行が受け付けられても、表示が復旧したとは限りません。
3. 問題が続く場合は、コピーしたレポートがあれば[不具合報告](https://github.com/daichan132/Youtube-Live-Chat-Fullscreen/issues/new?template=bug.yml)に添付してください。ポップアップでタブの状態を確認できない場合や、ボタンが使えない場合は、YouTube のページを再読み込みしてから、もう一度試してください。

レポートはクリップボードへコピーする前に匿名化され、URL、動画 ID、チャット本文、ユーザー名を含みません。見つかったページ要素、`IFRAME_DOCUMENT_NOT_READY` などの失敗コード、互換性を識別する情報を記録します。チャットの内容を共有せずに、メンテナが問題を調べるために使えます。

## パネルが勝手に移動した

手動で配置を変える前は、自動配置によって字幕、プレイヤーの操作ボタン、開いているメニュー、終了画面を避ける位置へ移動する場合があります。ドラッグ、サイズ変更、「配置調整」のボタン操作を行うと、保存した配置では自動配置が無効になります。プレイヤーの大きさが変わった場合は、その中に収まるようにパネルも調整されます。

## 不具合を報告する

[既存の報告](https://github.com/daichan132/Youtube-Live-Chat-Fullscreen/issues)を検索し、同じ問題がまだ報告されていなければ、[不具合報告フォーム](https://github.com/daichan132/Youtube-Live-Chat-Fullscreen/issues/new?template=bug.yml)を使ってください。次の情報を含めてください。

- ブラウザ、OS、拡張機能のバージョン。
- ライブ配信、アーカイブのリプレイ、チャットなしの動画のどれか。関係する場合は、ライブ配信への直接アクセスか、チャンネルのライブページから開いたかも記載してください。
- 動画を開いてから問題が起きるまでの手順と、期待した動作。
- 匿名化済みの診断レポート（利用できる場合）、個人情報を取り除いたスクリーンショットや録画。

公開動画のリンクは安全に共有できる場合にだけ記載してください。脆弱性は [SECURITY.md（英語）](../../SECURITY.md) の手順で非公開で報告してください。
