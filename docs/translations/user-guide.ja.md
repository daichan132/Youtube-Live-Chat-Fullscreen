# フルスクリーンでチャットを見る

YouTube Live Chat Fullscreen は、YouTube のチャットを動画に重ねて表示する拡張機能です。このガイドでは普段使う操作を説明します。インストール先と表示例は [README](README.ja.md) にあります。

## チャットを表示する

1. [Chrome ウェブストア](https://chromewebstore.google.com/detail/youtube-live-chat-fullscr/dlnjcbkmomenmieechnmgglgcljhoepd) または [Firefox アドオン](https://addons.mozilla.org/ja/firefox/addon/youtube-live-chat-fullscreen/)からインストールします。
2. ライブ配信、またはチャットリプレイを再生できるアーカイブを開きます。
3. YouTube プレイヤーの全画面ボタンでフルスクリーンにします。チャット表示は初期状態で有効です。プレイヤーのチャットボタンで表示をオン・オフにできます。

拡張機能を無効にしていた場合は、ブラウザのツールバーからポップアップを開いて有効にします。テーマは「ライト」「ダーク」、システム設定に合わせる「自動」から選べ、表示言語も変更できます。

チャットには YouTube 本来の機能を使います。ログインやライブ配信中の投稿は YouTube の通常のルールに従い、拡張機能用のアカウントは必要ありません。アーカイブのチャットは元の会話のリプレイです。

*標準のチャットと入力欄を表示した例です。入力途中のメッセージは送信していません。画像では視聴者の情報をぼかしています。配信映像：Kazama Iroha / hololive。[出典とプライバシー処理（英語）](../store-assets/chrome-web-store/README.md#sources-and-privacy)。*

## パネルの位置とサイズを変える

パネルにポインターを重ねると操作ボタンが表示されます。点が並んだ移動ハンドルをドラッグすると位置を、辺や角をドラッグするとサイズを変更できます。パネルを細くすると映像のためのスペースが増え、広くすると長いメッセージを表示しやすくなります。

左右の矢印の「配置調整」ボタンを選ぶと、パネルの位置や幅・高さを少しずつ変更できます。Tab キーで操作ボタンへ移動し、キーボードで使うこともできます。

配置はプレイヤーを基準に保存するため、フルスクリーンの大きさが変わっても対応できます。自動配置によって、字幕やプレイヤーの操作ボタンを避ける位置へ移動することもあります。手動で変更した配置が自動配置より優先されます。

## 見た目を調整する

パネルの操作ボタンから、スライダーの形をした「設定を開く」を選びます。

見た目や配置の変更は調整を終えると自動で保存されます。

| 設定 | 用途 |
| --- | --- |
| フォントサイズ・フォントファミリー | 視聴する距離に合わせて文字を読みやすくする |
| 文字色・メンバー名の色 | 背景に対して文字を読みやすくする |
| 背景色・透明度・ぼかし | 映像が複雑な場面でもチャットを見分けやすくする |
| 間隔 | メッセージ同士の間隔を広げる |
| ユーザー名を表示・ユーザーアイコンを表示 | 通常メッセージの表示を簡素にする。有料メッセージの送信者情報は表示したままになる |
| 操作していないときも表示 | プレイヤーの操作ボタンが消えてもチャットを表示する |
| チャットのみ表示 | ポインターを重ねるまでヘッダーと入力欄を折りたたむ |

README の例のように背景を完全に透明にするには、「背景色」を開き、一番下の透明度のスライダーを左端の 0% にして、「ぼかし」を 0 にします。メッセージだけのレイアウトにする場合は、「操作していないときも表示」をオンにしてから「チャットのみ表示」をオンにします。入力欄を表示したままにしたい場合は、「チャットのみ表示」をオフにしてください。古いパソコンで動作が重く感じられる場合は、ぼかしを弱めてください。

設定の操作項目には読み上げ用のラベルがあり、キーボードでも操作できます。パネルのドラッグや辺からのサイズ変更にはポインターを使います。代わりに「配置調整」のボタンを使うこともできます。

## プリセットを保存する

「プリセット」タブを開き、使いたい見た目の「適用」を選びます。組み込みのプリセットから試せます。

- 「透明」はぼかしのある半透明の背景です。
- 「大きめ」は大きな文字と明るい背景です。
- 「チャットのみ」は通常メッセージのユーザー名とアイコンを非表示にし、ポインターを重ねるまでヘッダーと入力欄を折りたたみます。

今の見た目に名前を付けて残すには、「現在の設定を追加」を選び、新しいプリセットの名前を「無題」から分かりやすい名前に変えます。ゲームを見るためのコンパクトな見た目と、ゆったり読むための見た目を保存して、切り替えて使えます。

プリセットには見た目と表示方法を保存します。「操作していないときも表示」や「チャットのみ表示」の設定も含みます。パネルの位置とサイズは別に保存するため、プリセットを選んでもパネルは移動しません。

## 設定をバックアップ・移行する

ブラウザのツールバーからポップアップを開くと、設定を JSON ファイルに書き出せます。別のブラウザやプロファイルへ移すには、「読み込み」からファイルを選び、確認画面の内容を確かめて「適用」を選びます。

バックアップには、拡張機能の有効状態、テーマ、見た目、名前付きプリセット、パネルの位置とサイズが含まれます。表示言語はブラウザごとの設定で、バックアップには含まれません。設定はローカルに保存され、アカウントを通じて自動で同期する機能はありません。

読み込みによってバックアップ対象の設定が置き換わります。今の設定も残したい場合は、先に書き出してください。

## チャットを利用できない場合

通常の動画や、利用できるチャットがない配信では、フルスクリーンにしてもチャットを重ねて表示しません。アーカイブでは、YouTube のチャットリプレイが利用でき、再生できる必要があります。YouTube が提供していないチャットを拡張機能で追加することはできません。

チャットが利用できるのにパネルが表示されない場合や、配置の操作に反応しない場合は、[トラブル対処](troubleshooting.ja.md)を参照してください。ブラウザのツールバーからポップアップを開くと「チャット表示を再試行」を使えます。レポートが利用できる場合は「診断をコピー」も使えます。

## プライバシー

設定はこのブラウザ内に保存されます。拡張機能にアクセス解析やトラッキングサービスはなく、チャット本文や閲覧履歴を開発者へ送信しません。YouTube のチャットは YouTube のサービスを利用し、選択した追加フォントは Google Fonts から読み込む場合があります。
