YouTube લાઇવ સ્ટ્રીમ ફુલસ્ક્રીન કરતાં જ ચેટ ગાયબ થઈ જાય છે. આ એક્સ્ટેન્શન તેને વિડિઓની ઉપર પાછી લાવે છે — ફુલસ્ક્રીન છોડ્યા વિના દરેક મેસેજ વાંચો, જવાબ આપો, અને લાઇવ સ્ટ્રીમ પર Super Chat મોકલો.

■ મુખ્ય સુવિધાઓ
- સ્થાન અને કદ: પેનલને પ્લેયર પર ગમે ત્યાં ખેંચી જાઓ, કોઈ પણ કિનારી કે ખૂણેથી કદ બદલો; બંને પ્લેયર સાથે જ મોટાં-નાનાં થાય છે, એટલે લેપટોપ પર નક્કી કરેલો લેઆઉટ 32 ઇંચની સ્ક્રીન પર પણ બંધબેસે છે.
- લખાણ: "ફોન્ટનું કદ" 10px થી 40px (ડિફોલ્ટ 13px; 40px એટલે સામાન્ય ચેટના લખાણ કરતાં લગભગ ત્રણ ગણું), તમારી પસંદનો "ફોન્ટનો રંગ", સભ્યોના નામ માટે અલગ રંગ, અને 50 ફોન્ટ.
- પૃષ્ઠભૂમિ: શરૂઆતમાં નક્કર સફેદ; એક જ પિકરમાંથી રંગ અને પારદર્શકતા, સાથે 0-20px "ધૂંધળાપણું" — ચાલવાની સરળતા સૌથી પહેલાં આ સેટિંગ જ છીનવી શકે, એટલે જૂનાં મશીનો પર તેને ઓછું જ રાખો.
- દેખાવું: "નિષ્ક્રિય હોય ત્યારે ચેટ બતાવો" શરૂઆતથી જ ચાલુ છે, એટલે પ્લેયરના કંટ્રોલ અદૃશ્ય થયા પછી પણ ચેટ ટકી રહે છે; એ ચાલુ હોય ત્યારે "ફક્ત ચેટ બતાવો" પસંદ કરો — પોઇન્ટર મૂકો ત્યાં સુધી હેડર અને લખવાનું ખાનું સંકેલાયેલાં રહે છે.
- નામ અને અંતર: સામાન્ય મેસેજ પર "વપરાશકર્તાનું નામ બતાવો" અને "પ્રોફાઇલ ચિત્ર બતાવો" બંધ કરી શકાય (ચૂકવણીવાળા મેસેજ પર એ રહે છે); મેસેજ વચ્ચે "અંતર" 0-40px.
- પ્રીસેટ: સાત પહેલેથી છે, દરેક એક ક્લિકમાં; તમારું પોતાનું પણ સાચવો.
- કીબોર્ડ: સ્લાઇડર અને પિકર તીર કીથી ચાલે છે, દરેક કંટ્રોલ પર સ્ક્રીન રીડર માટે લેબલ છે; માઉસ ફક્ત કંટ્રોલ હાર બોલાવવા, "ફક્ત ચેટ બતાવો" જે સંકેલે છે તે પાછું લાવવા અને કદ બદલવા માટે જોઈએ. દરેક ફેરફારે પોપઅપ, કંટ્રોલ હાર અને સેટિંગ્સ પેનલ પર WCAG 2.1 AA ની સ્વયંસંચાલિત તપાસ ચાલે છે.

■ નકલ નહીં — YouTube ની પોતાની ચેટ
વિડિઓ ઉપરની પેનલ એ સાઇડબારમાં આવતી YouTube ની પોતાની લાઇવ ચેટ જ છે, ફક્ત નવા રંગરૂપમાં — એટલે બેજ, ઇમોજી, સ્ટીકર અને મેમ્બર-ઓન્લી ચેટ પહેલાંની જેમ જ ચાલે છે. મેસેજ જાય છે YouTube ના પોતાના બોક્સમાંથી, Super Chat જાય છે તેની પોતાની ખરીદી પેનલમાંથી: પૈસા YouTube ને જાય છે, એક્સ્ટેન્શનને ક્યારેય નહીં. એ પેનલમાં એક્સ્ટેન્શન ફક્ત મેમ્બરશિપનું કંટ્રોલ બદલે છે — દબાવતાં ચેનલનું જોડાવાનું પેજ નવી ટેબમાં ખૂલે છે.

■ કિંમત કેટલી, ડેટા શું લે છે
મફત — સાઇન-અપ નહીં, પેઇડ પ્લાન નહીં.
પરવાનગીઓ બે, activeTab અને storage; કોડ ચાલે છે ફક્ત www.youtube.com પર — ઇન્સ્ટોલ કરતી વખતે તમારા ડેટા વિશે Chrome જે કહે છે તેનો અર્થ આટલો જ છે. બેકગ્રાઉન્ડમાં કશું ચાલતું નથી: કોઈ YouTube ટેબ ખુલ્લી ન હોય ત્યારે ફક્ત ટૂલબારનું પોપઅપ જ કંઈ કરે છે, અને એ પણ ખુલ્લું હોય ત્યાં સુધી જ.
એનાલિટિક્સ નહીં, ટ્રેકિંગ નહીં, ડેવલપર સુધી કશું જતું નથી: તમે જે વાંચો અને લખો તે ભેગું કરાતું, સાચવાતું કે ક્યાંય મોકલાતું નથી; સેટિંગ્સ આ જ બ્રાઉઝરમાં રહે છે. બધો કોડ એક્સ્ટેન્શનની અંદર જ આવે છે; ડિફોલ્ટ સિવાયનો ફોન્ટ પસંદ કરો ત્યારે જ તે Google Fonts પરથી આવે છે. GPL-3.0 હેઠળ ઓપન સોર્સ, GitHub પર જાહેર.

■ શરૂ કેવી રીતે કરવું
1. ઇન્સ્ટોલ કરો, પછી કોઈ લાઇવ સ્ટ્રીમ કે ચેટ રિપ્લેવાળું આર્કાઇવ ખોલો.
2. પ્લેયરને ફુલસ્ક્રીન કરો — ચેટ પહેલેથી જ ત્યાં છે.
3. કંટ્રોલ બારનું સ્પીચ-બબલ બટન તેને બંધ અને ચાલુ કરે છે; ચેટ પર પોઇન્ટર મૂકતાં તેનું પોતાનું સેટિંગ્સ બટન દેખાય છે, જે દેખાવ બદલે છે.

■ ક્યાં ચાલે છે
ફક્ત ડેસ્કટોપ પર, ચેટવાળા વોચ પેજના ફુલસ્ક્રીનમાં. આ Chrome બિલ્ડ Opera માં પણ ચાલે છે; Firefox માટે અલગ બિલ્ડ addons.mozilla.org પર છે. એક્સ્ટેન્શનની ભાષા માટે 49 ભાષાઓમાં 55 વિકલ્પો છે.
