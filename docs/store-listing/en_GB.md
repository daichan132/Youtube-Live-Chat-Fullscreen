Go full screen on a YouTube live stream and the chat disappears. This extension puts it back over the video, so you can read every message, reply and — on a live stream — send Super Chats without leaving full screen.

MAIN FEATURES
- Position and size: drag it anywhere over the player, resize from any edge or corner; both scale with the player, so a laptop layout fits a 32-inch monitor.
- Text: Font size runs 10px to 40px (13px by default; 40px is about three times normal chat text), your own text colour, a separate one for member names, 50 fonts.
- Background: solid white to start; colour and transparency from one picker, plus 0-20px Blur — the setting likeliest to cost smoothness, so go easy on an older machine.
- Visibility: Show When Idle ships on, so the chat stays up after the controls fade; with it on, Chat-Only Mode folds away the header and message box until you hover.
- User names and spacing: hide user names and profile pictures on ordinary messages, paid ones keep theirs; Spacing runs 0-40px between messages.
- Presets: seven built in, one click each, plus your own.
- Keyboard: sliders and pickers take arrow keys, every control is labelled for a screen reader; only resizing, and calling up the control row or what Chat-Only Mode folds away, need a mouse. Automated WCAG 2.1 AA checks cover the popup, control row and settings panel on every change.

YOUTUBE'S OWN CHAT, NOT A LOOKALIKE
The panel over the video is YouTube's own live chat from the sidebar, restyled, so badges, emoji, stickers and members-only chat keep working. Posting uses YouTube's own message box, Super Chats its purchase panel: payment goes to YouTube, never the extension. The one control it changes there is Membership: it opens the channel's join page in a new tab.

WHAT IT COSTS AND WHAT IT COLLECTS
Free: no sign-up, no paid tier.
Two permissions, activeTab and storage; www.youtube.com is the only site it runs on — that is all Chrome's install prompt about your data means. Nothing runs in the background: with no YouTube tab open, only the toolbar popup does anything, and only while open.
No analytics, no tracking, nothing to the developer: it never collects, stores or sends what you read or type; settings stay in this browser. All code ships inside the extension; only fonts beyond the default come from Google Fonts. Open source under GPL-3.0, public on GitHub.

HOW TO START
1. Install it, then open a live stream or an archive with chat replay.
2. Put the player in full screen — the chat is already there.
3. A speech-bubble button in the control bar toggles it; hover the chat and its settings button changes the look.

WHERE IT RUNS
Desktop only, in full screen on a watch page with chat. This Chrome build also runs in Opera; Firefox has its own build on addons.mozilla.org. The interface comes in 55 options across 49 languages.
