全画面にすると、チャットが消える。

この拡張機能は、消えたチャットを動画の上に呼び戻します。全画面のまま、コメントを読んで、書き込んで、ライブ配信ならスーパーチャットも送れます。最初は、透けない白いパネルに黒い文字。色も、透明度も、文字の大きさも、あとから自由に変えられます。

プレーヤーを縮めることも、シアターモードやポップアウトに切り替えることもありません。全画面にすれば、コメントはもう映像の上にあります。オン・オフは、コントロールバーに追加されるボタンひとつ。無料、アカウント登録なし、ソースコードは公開。パソコンのブラウザ向けで、動くのはYouTubeの中だけです。

■ 似せたチャットではなく、YouTube本体のチャットそのもの
動画の上に重ねているのは、サイドバーに出るのと同じ、YouTube自身が表示しているライブチャットの画面です。
メンバーバッジも絵文字も、入力欄も、スーパーチャットとスーパーステッカーの購入パネルも、YouTube本体のものです。書き込みはその入力欄から送るので、ログインはいつもどおり必要です。さかのぼってスクロールしたときの動きも、メンバー限定チャットの見え方も、サイドバーで見るときと同じです。
この拡張機能が変えるのは、基本的に色や文字の大きさ、間隔といった見た目です。

■ 大画面で音楽ライブを観る
文字サイズは40pxまで上げられます。「操作していないときも表示」は最初からオンなので、パネルを画面の隅に置いておけば、再生コントロールが消えたあともメッセージは残ります。

■ サブモニターでゲーム配信を流す
「チャットのみ表示」をオンにすると、ヘッダーと入力欄が畳まれて、メッセージだけが並びます。カーソルを重ねれば、ヘッダーも入力欄もいつでも戻せます。（この設定は「操作していないときも表示」がオンのときだけ選べます。）あとは画面の端で細長くリサイズして、背景に少しぼかしを入れれば、明るいゲーム画面の上でも読めて、映像の邪魔になりません。

■ 深夜にアーカイブを見返す
チャットリプレイが残っている配信なら、当時のコメントを動画の上に重ねて見返せます。見た目の設定は、追っかけ再生でもアーカイブでも、ライブのときのままです。
再生位置を動かしても速度を変えても、コメントはサイドバーと同じようについてきます。中身も同じで、この拡張機能が足すことも減らすこともありません。

■ プリセットで見た目をまとめて切り替える
内蔵のプリセットは7つ。たとえば「大きめ」は、ほとんど透けない白いパネルに18pxの黒文字。ユーザー名とアイコンを隠し、ぼかしもオフ。離れて観るときは、これを選ぶだけです。いまの設定に名前を付けて保存すれば、自分のプリセットもワンクリックで呼び出せます。名前の変更も並べ替えも削除も自由です。

■ 調整できること
位置：ドラッグでプレーヤー上の好きな場所へ。パネルにカーソルを重ねると、そのすぐ下の右端に設定ボタンと移動ハンドルが出ます（画面の下端に近いときは、パネルに重なります）。ハンドルが出ているあいだは、Tabキーでそこへ移って矢印キーで10pxずつ動かせます。置き場所を自分で決めるまでは、字幕やメニュー、終了画面やコントロールバーにかぶりそうになると、いちばん邪魔にならない隅へ一度だけ自動で移ります。決めたあとは動きません。
サイズ：四辺と四隅のどこからでもつかんで、細い帯にも縦長の列にもできます。はじめの大きさは、プレーヤーの横幅の約3分の1、高さの半分強。位置と大きさはプレーヤーを基準に覚えるので、ノートパソコンで決めた配置が外部モニターでもそのまま使えます。
背景：カラーピッカーで色と透明度を指定できます。0〜20pxのぼかしを足せば、にぎやかな映像の上でも文字が埋もれません。ぼかしは最初はオフ（0）。入れると動作が重くなりやすいので、古いパソコンでは0のままがおすすめです。
文字：サイズ（パネルでは「フォントサイズ」）は10〜40px、最初は13px。上限の40pxは、YouTube標準の文字のおよそ3倍。パネルの大きさを変えても、文字サイズはそのままです。文字色とメンバー名の色も、それぞれ選べます。フォントは日本語対応のものを含めて50種類。選んだ瞬間に、チャットの見た目が変わります。
間隔：メッセージのあいだは0〜40px。通常のメッセージのユーザー名とアイコンは、それぞれ隠せます（スーパーチャットの名前とアイコンは残ります）。チャット上部のスーパーチャットバーも消せます。
表示：「操作していないときも表示」をオフにすると、マウスやキーボードの操作が1秒ほど止まったところでパネルが消え、また動かすと戻ります。
取り消し：設定パネルを開いているあいだは、色や文字サイズなどの変更を Cmd/Ctrl+Z で取り消し、Shift+Cmd/Ctrl+Z でやり直せます（最大50回）。パネルの位置と大きさだけは、この取り消しでは戻りません。
テーマ：拡張機能自体の画面は、ツールバーのポップアップで「ライト」「ダーク」、パソコンの設定に合わせる「自動」の3つから選べます。
言語：表示言語も同じポップアップで、ブラウザとは別に選べます。選択肢は55、言語としては49。英語・スペイン語・ポルトガル語・中国語は地域ごとに分かれ、アラビア語・ヘブライ語・ペルシャ語は右から左のレイアウトに対応します。

■ ボタンひとつで、いつものYouTubeに戻る
YouTube側のチャットボタンを押せば、オーバーレイは自動で消えて、ページはいつもどおりに戻ります。オンとオフは、プレーヤーのボタンからも、ツールバーのアイコンからも切り替えられます。パネルの中でのクリックやスクロールは下の動画に伝わらないので、手が滑って再生が止まったり、再生位置が飛んだりすることはありません。パネルの外では、これまでどおりプレーヤーが反応します。

■ 料金とプライバシー
無料です。アカウント登録も、有料プランもありません。
権限は activeTab と storage の2つだけ。ウェブページの中で動くのは www.youtube.com だけです。インストール時にChromeが表示する「データの読み取りと変更」は、この1サイト分のことです。バックグラウンドで動き続ける仕組みはなく、YouTubeのタブを開いていないあいだに動くのは、ポップアップを開いたときだけです。コードはすべて拡張機能の中に入っていて、あとから外部のサーバーから読み込むことはありません。唯一の例外がフォントです。初期設定以外のフォントを選ぶと（それを使うプリセットに切り替えたときも）、そのフォントだけを Google Fonts から読み込みます。初期設定のままなら、何も取りにいきません。
アクセス解析もトラッキングも入れていません。読んだメッセージも入力した文字も、集めたり外へ送ったりしません。開発者に届くデータは一つもありません。スーパーチャットとスーパーステッカーの購入パネルはYouTube本体のもので、支払いもYouTube側で完結します。（このパネルの中の「メンバーシップ」だけは、押すとチャンネルの参加ページが新しいタブで開きます。）設定はこのパソコンのブラウザの中だけに保存し、Googleアカウント経由で同期することはありません。ファイルに書き出して、別のパソコンで読み込むこともできます。

■ 使い方
1. インストールして、ライブ配信（またはチャットリプレイ付きのアーカイブ）を開く
2. プレーヤーを全画面にする
3. コメントが映像の上に出る。最初からオンなので、何も押さなくていい
4. オン・オフはコントロールバー右下の吹き出しボタンから、見た目の調整はパネルの設定ボタンから。どちらも次の配信に引き継がれる

オーバーレイが出るのは、視聴ページを全画面にしていて、重ねられるチャットがあるときだけです。ウィンドウ表示やシアターモードでは、YouTube自身がチャットを出せるので、重ねる必要がありません。チャットのない動画や、チャットリプレイの残っていない配信では、ボタン自体が出てきません。このストアのChrome版は、OperaなどChromium系のブラウザでも使えます。Firefox版は addons.mozilla.org にあります。

■ キーボード操作と、うまく動かないときの対処
設定パネルは、ほとんどキーボードとスクリーンリーダーだけで操作できます。コントロールにはすべてラベルが付き、スライダーもカラーピッカーも矢印キーで動くので、文字サイズも間隔も配色もマウスなしで決められます。マウスが必要なのは2つだけ。パネルにカーソルを重ねて設定ボタンと移動ハンドルを出すときと、パネルをリサイズするときです。メッセージはYouTubeのままなので、読み上げもサイドバーと同じです。アクセシビリティの自動チェック（WCAG 2.1 AA）は、コードを変えるたびに実行しています。対象は、ポップアップ、設定パネル、そして設定ボタンと移動ハンドルです。
YouTube側の仕様変更は頻繁ですが、2023年から追いかけて直し続けています。それでも動かないときは、設定パネルで状態を確かめ、再起動ボタンを押すか、診断レポートをコピーしてください。レポートに入るのは、拡張機能のバージョンとブラウザの種類、そしてページのどこにチャットを重ねられたかの記録です。動画やチャンネル、個人を特定できる情報は含みません。コピー先はクリップボードだけで、どこにも送りません。
