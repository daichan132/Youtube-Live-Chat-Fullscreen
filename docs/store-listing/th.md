ดู YouTube แบบเต็มหน้าจอ พร้อมอ่านและส่งข้อความในแชทสดได้
YouTube แชทสดแบบเต็มหน้าจอเป็นส่วนขยาย Chrome ฟรีที่วางแชทซ้อนบนวิดีโอ คุณจึงดูไลฟ์และร่วมพูดคุยได้โดยไม่ต้องออกจากโหมดเต็มหน้าจอ

ทั้งไลฟ์สดและแชทย้อนหลัง
ดูสตรีมเกม VTuber และอีเวนต์ถ่ายทอดสดไปพร้อมกับปฏิกิริยาของผู้ชม สำหรับวิดีโอย้อนหลังที่มีแชทรีเพลย์ คุณสามารถดูบทสนทนาจากการถ่ายทอดสดครั้งนั้นควบคู่กับวิดีโอได้

ปรับแชทให้เหมาะกับการรับชม
- พื้นหลังโปร่งใส: ปรับความทึบและความเบลอเพื่อให้เห็นวิดีโอหลังแชท
- ตำแหน่งและขนาด: ลากแผงแชทหลบจุดสำคัญของวิดีโอ แล้วปรับความกว้างและความสูงได้
- ตัวอักษรอ่านง่าย: เลือกแบบอักษร ขนาดและสีข้อความ สีพื้นหลัง และระยะห่างระหว่างข้อความ
- รูปแบบที่บันทึกไว้: เลือกสไตล์ที่มีให้ หรือบันทึกการตั้งค่าหน้าตาแชทของคุณเอง
- แสดงผลให้กระชับ: ซ่อนชื่อและรูปโปรไฟล์ในข้อความทั่วไป หรือพับช่องพิมพ์ไว้จนกว่าคุณจะโต้ตอบกับแชท

ใช้แชทของ YouTube ได้ตามปกติ
แผงแชทใช้ระบบแชทเดิมของ YouTube ทั้งอีโมจิ ป้ายสมาชิก และช่องพิมพ์ข้อความ การส่งข้อความระหว่างไลฟ์ต้องลงชื่อเข้าใช้ ส่วน Super Chat ใช้ได้ในไลฟ์ที่รองรับ การส่งข้อความและใช้ฟีเจอร์แบบเสียเงินขึ้นอยู่กับเงื่อนไขของแพลตฟอร์มและการตั้งค่าของช่อง แชทในวิดีโอย้อนหลังเป็นการเล่นบทสนทนาเดิม ไม่ใช่ห้องสนทนาสดครั้งใหม่

วิธีใช้งาน
1. ติดตั้งส่วนขยาย แล้วเปิดไลฟ์หรือวิดีโอย้อนหลังที่มีแชทรีเพลย์
2. กดปุ่มเต็มหน้าจอในเครื่องเล่นวิดีโอ
3. วางเคอร์เซอร์บนแชทเพื่อย้าย ปรับขนาด หรือเปิดการตั้งค่า
ใช้ปุ่มแชทบนแถบควบคุมเครื่องเล่นเพื่อแสดงหรือซ่อนแผงแชท หากเคยปิดฟังก์ชันไว้ ให้เปิดแชทเต็มหน้าจอในป๊อปอัปของส่วนขยายบนแถบเครื่องมือ

ฟรีและโอเพนซอร์ส
ไม่ต้องสมัครบัญชีหรือจ่ายค่าสมาชิกแยกสำหรับส่วนขยาย ซอร์สโค้ดเปิดเผยบน GitHub ภายใต้สัญญาอนุญาต GPL-3.0 ส่วนฟีเจอร์แบบเสียเงินของแพลตฟอร์มวิดีโอยังคงมีค่าใช้จ่ายแยกต่างหาก

ความเป็นส่วนตัวและสิทธิ์
การตั้งค่าจัดเก็บไว้ในเบราว์เซอร์นี้ผ่านสิทธิ์ storage ส่วนขยายทำงานบนหน้า www.youtube.com เท่านั้น ไม่มีการวิเคราะห์หรือติดตาม และไม่ส่งเนื้อหาแชทหรือประวัติการรับชมให้ผู้พัฒนา แชทเดิมเชื่อมต่อกับบริการของ YouTube ส่วนแบบอักษรที่เลือกเพิ่มเติมจะโหลดจาก Google Fonts

อุปกรณ์และเบราว์เซอร์ที่รองรับ
สำหรับ Chrome บนคอมพิวเตอร์ ใช้กับวิดีโอที่มีแชทสดหรือแชทรีเพลย์ที่พร้อมใช้งาน วิดีโอที่ไม่มีแชทจะไม่แสดงแผงแชท การทำงานใน Opera และเบราว์เซอร์อื่นที่ใช้ Chromium อาจแตกต่างกัน มีเวอร์ชัน Firefox แยกที่ addons.mozilla.org การตั้งค่ารองรับการใช้แป้นพิมพ์ และมีตัวเลือกภาษาของหน้าจอ 55 แบบ
