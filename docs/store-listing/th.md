เปิดไลฟ์ของ YouTube แบบเต็มจอเมื่อไร แชทก็หายไปเมื่อนั้น ส่วนขยายนี้ดึงแชทกลับมาวางไว้บนวิดีโอ ให้คุณอ่านทุกข้อความ พิมพ์ตอบ และถ้าเป็นไลฟ์ก็ส่ง Super Chat ได้ โดยไม่ต้องออกจากเต็มจอ

■ ความสามารถหลัก
- ตำแหน่งและขนาด: ลากแผงไปวางตรงไหนก็ได้บนตัวเล่น ปรับขนาดได้จากทุกด้านและทุกมุม ทั้งสองอย่างขยายไปพร้อมกับตัวเล่น ตำแหน่งที่จัดไว้บนโน้ตบุ๊กจึงใช้กับจอ 32 นิ้วได้เลย
- ตัวอักษร: "ขนาดข้อความ" 10-40px (ค่าเริ่มต้น 13px ส่วน 40px ใหญ่กว่าตัวอักษรแชทปกติราวสามเท่า) เลือก "สีข้อความ" เอง แยก "สีชื่อสมาชิก" ได้ต่างหาก และมีแบบอักษรให้เลือก 50 แบบ
- พื้นหลัง: เริ่มต้นเป็นสีขาวทึบ เลือก "สีพื้นหลัง" กับความโปร่งใสจากตัวเลือกเดียวกัน แล้วเพิ่ม "ความเบลอ" ได้ 0-20px ซึ่งเป็นการตั้งค่าที่ทำให้ภาพสะดุดง่ายที่สุด เครื่องเก่าจึงควรใช้แต่พอดี
- การแสดงผล: "แสดงแชทเมื่อไม่มีการใช้งาน" เปิดมาให้ตั้งแต่แรก แชทจึงยังอยู่แม้แถบควบคุมจะจางหายไป และเมื่อเปิดค้างไว้ "โหมดแสดงเฉพาะแชท" จะพับแถบหัวและช่องพิมพ์เก็บไว้ จนกว่าจะเลื่อนเมาส์ไปวาง
- ชื่อผู้ใช้และระยะห่าง: ปิด "แสดงชื่อผู้ใช้" กับ "แสดงรูปโปรไฟล์" ของข้อความทั่วไปได้ ส่วนข้อความแบบเสียเงินยังคงชื่อและรูปไว้ และปรับ "ระยะห่างระหว่างข้อความ" ได้ 0-40px
- ค่าตั้งล่วงหน้า: มีมาให้เจ็ดแบบ กดครั้งเดียวเปลี่ยนได้ทั้งชุด และบันทึกของคุณเองเพิ่มได้
- แป้นพิมพ์: แถบเลื่อนและตัวเลือกสีใช้ปุ่มลูกศรได้ ทุกปุ่มมีป้ายกำกับสำหรับโปรแกรมอ่านหน้าจอ เมาส์จำเป็นเฉพาะตอนเรียกแถบปุ่มขึ้นมา ตอนเรียกส่วนที่ "โหมดแสดงเฉพาะแชท" พับเก็บไว้ให้กลับมา และตอนปรับขนาด และมีการตรวจ WCAG 2.1 AA อัตโนมัติทุกครั้งที่แก้โค้ด ครอบคลุมป๊อปอัป แถบปุ่ม และแผงการตั้งค่า

■ แชทของ YouTube เอง ไม่ใช่ของเลียนแบบ
แผงที่ซ้อนอยู่บนวิดีโอคือไลฟ์แชทของ YouTube ตัวเดียวกับที่อยู่แถบข้าง แต่เปลี่ยนหน้าตาใหม่ แบดจ์ อิโมจิ สติกเกอร์ และแชทเฉพาะสมาชิกจึงยังทำงานเหมือนเดิม การพิมพ์ส่งผ่านช่องข้อความของ YouTube และ Super Chat ก็ผ่านแผงชำระเงินของ YouTube เงินจึงไปที่ YouTube ไม่ใช่ส่วนขยาย สิ่งเดียวในแผงนั้นที่ส่วนขยายเปลี่ยนคือปุ่มสมาชิก (Membership) ซึ่งจะเปิดหน้าสมัครของช่องขึ้นในแท็บใหม่

■ ราคาและข้อมูลที่เก็บ
ใช้ฟรี ไม่ต้องสมัครบัญชี ไม่มีแบบเสียเงิน
ขอสิทธิ์สองอย่าง คือ activeTab กับ storage และทำงานเฉพาะบน www.youtube.com เท่านั้น คำเตือนเรื่องข้อมูลตอนติดตั้งของ Chrome หมายถึงแค่นี้ ไม่มีอะไรทำงานอยู่เบื้องหลัง ถ้าไม่มีแท็บ YouTube เปิดอยู่ สิ่งที่ทำงานคือหน้าต่างป๊อปอัปบนแถบเครื่องมือเท่านั้น และทำงานเฉพาะตอนที่เปิดค้างไว้
ไม่มีการเก็บสถิติ ไม่มีการติดตาม ไม่มีอะไรส่งถึงผู้พัฒนา ข้อความที่คุณอ่านหรือพิมพ์ไม่ถูกเก็บ ไม่ถูกบันทึก และไม่ถูกส่งออกไปไหน การตั้งค่าอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น โค้ดทั้งหมดมาพร้อมตัวส่วนขยาย มีเพียงแบบอักษรนอกเหนือจากค่าเริ่มต้นที่ดึงมาจาก Google Fonts ซอร์สโค้ดเปิดเผยภายใต้ GPL-3.0 บน GitHub

■ เริ่มใช้อย่างไร
1. ติดตั้ง แล้วเปิดไลฟ์ หรืออาร์ไคฟ์ที่ยังมีแชทรีเพลย์
2. สั่งให้ตัวเล่นเต็มจอ แชทอยู่ตรงนั้นให้แล้ว
3. ปุ่มรูปกรอบคำพูดบนแถบควบคุมใช้เปิดปิดแชท ส่วนปุ่มการตั้งค่าที่โผล่มาเมื่อเลื่อนเมาส์ไปวางบนแชทใช้เปลี่ยนหน้าตา

■ ใช้ได้ที่ไหน
เฉพาะบนคอมพิวเตอร์ ในโหมดเต็มจอของหน้าดูวิดีโอที่มีแชทเท่านั้น เวอร์ชัน Chrome จากสโตร์นี้ใช้กับ Opera ได้ด้วย ส่วน Firefox มีเวอร์ชันของตัวเองอยู่ที่ addons.mozilla.org ภาษาของหน้าตาส่วนขยายมีให้เลือก 55 รายการ ครอบคลุม 49 ภาษา
