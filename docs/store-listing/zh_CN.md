YouTube 直播一进全屏，聊天就没了。

这个扩展程序把消失的聊天重新放回视频上。全屏状态下照样读消息、发言，直播时还能发 Super Chat。开关是播放控制栏里多出来的一个按钮。免费，而且网页里只在 YouTube 中运行。

■ 主要功能
- 位置和大小随你定：拖动就能移动，四边四角都能调整大小。位置和大小都以播放器为基准记住，笔记本上调好的布局，换到 32 英寸屏幕也合适。
- 离远也看得清的文字：“字体大小”为 10～40px，默认 13px。上限的 40px 约为平时聊天文字的三倍。“字体颜色”和“会员名称颜色”可以分开设置，字体有 50 种。
- 不被画面淹没的背景：一开始是不透明的白色面板。“背景色”里颜色和透明度一起选，还能加 0～20px 的“模糊”。模糊是最容易影响流畅度的设置，旧电脑上建议保持 0。
- 不会消失的聊天：“空闲时显示聊天”默认开启，播放控制栏隐去之后，消息依然留在画面上。开着它才能选的“仅显示聊天”会收起标题栏和输入框，只留下消息，鼠标移上去就恢复。
- 隐藏名字与间距：普通消息可以分别关掉“显示用户名”和“显示用户头像”（付费消息的名字和头像仍然保留）。消息之间的“间距”可在 0～40px 之间调整。
- 预设：内置七种，各点一下即可应用，也能把当前设置存成自己的预设。
- 键盘与无障碍：滑块和取色器都能用方向键调整，每个控件都带有读屏软件用的名称。需要鼠标的只有唤出控制栏和调整大小两处。每次改动代码，都会跑一遍 WCAG 2.1 AA 自动检查。

■ 不是仿制的聊天，而是 YouTube 自己的聊天
盖在视频上的，就是侧边栏里那个 YouTube 自己的实时聊天。它不是重做的界面，所以会员徽章、表情、贴纸、会员专属聊天都照常可用。发言用的是 YouTube 自己的输入框，Super Chat 用的是 YouTube 自己的购买面板，付款在 YouTube 一侧完成，钱不会经过这个扩展程序。这个面板里被改动的只有会员这一项，点了会在新标签页打开频道的加入页面。除此之外改动的，基本上是颜色、字号、间距这类外观。

■ 价格与隐私
免费。无需注册账号，也没有付费版本。
权限只有 activeTab 和 storage 两项，网页当中运行的只有 www.youtube.com。Chrome 安装提示里关于数据的那句话，指的就是这些。没有在后台常驻的部分，没开 YouTube 标签页时，会动的只有工具栏弹窗，而且仅限打开的那段时间。
没有统计分析，也没有追踪。读到的消息和输入的文字，都不收集、不保存、不外发，开发者这边也收不到数据。设置只留在这个浏览器里。代码全部随扩展程序一起提供，需要从外部获取的只有字体：选了默认以外的字体，才会从 Google Fonts 取得。源代码以 GPL-3.0 在 GitHub 上公开。

■ 开始使用
1. 装好之后，打开一场直播，或者打开保留了聊天回放的存档视频。
2. 把播放器切到全屏。聊天已经在视频上了。
3. 控制栏里的对话气泡按钮负责开关，设置按钮负责调整外观。

■ 运行环境与显示语言
仅限桌面，只在带聊天的观看页面进入全屏时出现。本商店的 Chrome 版同样可以在 Opera 上使用，Firefox 版在 addons.mozilla.org。显示语言可以和浏览器分开选，选项共 55 个，涵盖 49 种语言。
