YouTube 全屏播放时，也能看直播聊天、发消息。
YouTube 直播全屏聊天是一款免费的 Chrome 扩展，将聊天窗口叠加在视频上。无需退出全屏，就能一边看直播，一边参与讨论。

直播与聊天回放
看游戏直播、VTuber 或现场活动时，把观众的反应也留在画面里。对于提供聊天回放的直播录像，可以跟随视频重温当时的讨论。

按你的习惯调整聊天窗口
- 透明背景：调整透明度和模糊效果，让聊天背后的视频也看得见。
- 位置与尺寸：拖动窗口避开重要画面，并调整宽度和高度。
- 文字显示：选择字体、字号、文字颜色、背景颜色及消息间距。
- 样式预设：使用内置样式，或保存自己的外观设置。
- 简洁显示：隐藏普通消息的用户名和头像，或在没有操作时收起输入框。

直接使用 YouTube 聊天
窗口使用 YouTube 原有的聊天功能，包括表情、会员徽章和输入框。直播中发送消息需要登录。支持的直播也可使用 Super Chat；能否发言及使用付费功能，取决于平台的使用条件和频道设置。录像中的聊天是当时消息的回放，不是新的实时讨论。

使用方法
1. 安装扩展，打开直播或带聊天回放的直播录像。
2. 点击视频播放器的全屏按钮。
3. 将鼠标移到聊天窗口上，即可移动、调整大小或打开设置。
通过播放器控制栏中的聊天按钮，可显示或隐藏窗口。如果此前关闭了扩展功能，请在工具栏弹出窗口中开启全屏聊天。

免费且开源
无需为扩展另行注册账号或订阅。源代码以 GPL-3.0 许可证在 GitHub 上公开。视频平台提供的付费功能仍需单独付费。

隐私与权限
设置通过 storage 权限保存在当前浏览器中。扩展仅在 www.youtube.com 网页上运行，不进行统计分析或跟踪，也不会将聊天内容或观看记录发送给开发者。原有聊天会连接 YouTube 的服务；可选字体从 Google Fonts 加载。

支持环境
适用于桌面版 Chrome，支持带有直播聊天或可用聊天回放的视频。没有聊天的视频不会显示窗口。Opera 等其他 Chromium 浏览器的兼容情况可能因环境而异；Firefox 版可在 addons.mozilla.org 单独获取。设置支持键盘操作，并提供 55 种界面语言选项。
