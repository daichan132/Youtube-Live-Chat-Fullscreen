在 YouTube 直播里切到全屏，聊天就不见了。

这个扩展把它放回视频上方，让你不必退出全屏，就能读完每一条留言、回复，并在直播中发送 Super Chat 超级留言。面板一开始是不透明的白底黑字，颜色、透明度和字号都可以自己改。

不用缩小播放器，不用切到影院模式，也不用把聊天弹成小窗放到副屏——切到全屏，对话就在那里，控制栏上多出的一个按钮负责开关。免费、开源，仅限桌面浏览器。

■ 不是仿制的聊天，而是 YouTube 自己的聊天，搬到视频上
盖在视频上的，就是侧边栏里那个 YouTube 自己的实时聊天。会员徽章、表情、贴图、输入框，以及 Super Chat 和 Super Sticker 的购买面板，全都是 YouTube 本体的界面。发言经过那个输入框，所以照旧需要登录。往回翻看历史消息、会员专属聊天，表现都和播放器旁边一样。这个扩展不会重新生成消息，改动的主要是外观：颜色、大小和间距。

■ 用大屏幕看一场演唱会
把字号拉到 40px，把面板放到画面一角。“空闲时显示聊天”默认就是开着的，所以播放控件淡出之后，消息也会一直留在那里。

■ 在副屏上挂着游戏直播
打开“仅显示聊天”，标题栏和输入框会收起来，只剩一列干净的消息；把鼠标移上去，它们随时都能回来。只有“空闲时显示聊天”是开着的，才能在设置面板里找到它。再把面板拉成贴着屏幕一侧的细长条，加一点模糊：明亮的游戏画面上也读得清，又不挡视线。

■ 深夜补看录播
打开一场还留着聊天回放的往期直播，切到全屏，聊天就带着你调好的面板和样式回来了。拖动进度或改变倍速，聊天都会跟上，和侧边栏一样——留言还是那些留言，这个扩展不添、也不藏。

■ 每种直播都有合适的样子
内置七套预设。选“大字”——几乎不透明的白色面板配 18px 黑字，不显示用户名和头像——靠在沙发上也读得清。也可以把自己的一套存下来，随时改名、排序或删除。

■ 可以调整的地方
位置：把面板拖到播放器上的任意处。鼠标移到面板上，正下方靠右会出现一排控件——设置按钮和拖动手柄（靠近屏幕底部时，它会上移到面板上）。这排控件显示着的时候，用 Tab 键移到手柄上，方向键就能每次挪动 10px。面板从一角开始，当字幕、菜单、片尾画面或控制栏开始遮住它时，它会朝被遮得最少的那一角挪一次。你自己放好之后，它就不再动了。
大小：初始约为播放器宽度的三分之一、高度的一半多一点；拖动任意一条边或一个角，就能把它变成细长条或竖直的一列。位置和大小都按播放器换算，所以在笔记本上调好的布局，换到 32 英寸显示器也合适。
背景：颜色和不透明度在同一个“背景色”选择器里，另有 0–20px 的“模糊”，让面板在杂乱画面上像磨砂玻璃。模糊从 0 开始——这是唯一可能拖慢老机器的设置，老机器上建议保持 0。
文字：“字体大小”从 10px 到 40px，默认 13px——40px 大约是普通聊天文字的三倍。改变面板大小不会改动你选的字号。可以设置“字体颜色”，以及单独的“会员名称颜色”，还有 50 种“字体”（含日文字体），选中即刻生效。
间距：消息之间的“间距”为 0–40px，另有“显示 Super Chat 栏”开关，以及针对普通消息的“显示用户名”和“显示用户头像”开关（付费消息保留名字和头像）。
显示：可以让面板在你不动时也留着，也可以让它在鼠标和键盘安静一秒后淡出，你一动它就回来。
撤销：设置面板打开时，Cmd/Ctrl+Z 可逐步撤销外观改动，Shift+Cmd/Ctrl+Z 重做，最多 50 步——不含位置和大小。
主题：扩展自己的界面可在工具栏弹窗里选“浅色”“深色”或“自动”。
语言：显示语言也在同一个弹窗里，与浏览器语言无关——覆盖 49 种语言的 55 个选项，英语、西班牙语、葡萄牙语和中文分地区版本，阿拉伯语、希伯来语和波斯语支持从右到左的排版。

■ 一按就回到平常的 YouTube
按下 YouTube 自己的聊天按钮，浮层就会关掉，页面回到原样；播放器上的按钮和工具栏图标都能再把它打开。面板内的点击和滚动只留在聊天里，不会误按暂停或拖动进度；面板之外，播放器一切照旧。

■ 收费和收集
免费——不需要账号，也没有付费版。
两项权限：activeTab 和 storage。代码只在一个网站上运行，www.youtube.com——Chrome 安装提示里说的读取和更改数据，指的就是这一个网站。也没有常驻后台的部分：没有打开 YouTube 标签页时，只有正开着的工具栏弹窗在运行。所有代码都随扩展一起打包，唯一会从网上取的是字体。默认字体什么都不加载；换成别的字体，或切到用了别的字体的预设，才会从 Google Fonts 取。
没有分析、没有追踪，也没有任何东西发给开发者：你读到的和输入的内容，不会被收集、保存或发送到任何地方。Super Chat 的付款走的是 YouTube 的购买面板，而不是这个扩展；扩展在那个面板里改动的只有“会员”一项，点击后会在新标签页打开频道的加入页面。设置只留在这台电脑的这个浏览器里，不会通过 Google 账号同步；弹窗可以把设置导出成文件，在别处导入。
以 GPL-3.0 开源：完整代码公开在 GitHub 上，这里写的每一句你都可以自己去核对。

■ 怎么开始
1. 安装后，打开一场直播，或一个带聊天回放的录播。
2. 把播放器切到全屏。
3. 聊天就回到视频上方了——不用打开任何开关。
4. 控制栏右下角新增的对话气泡按钮负责开关，面板上的设置按钮负责调整外观。两者都会带到下一场直播。

面板只在全屏、且是带聊天的观看页面时出现——普通视频，或聊天回放已经没有了的直播，按钮根本不会出现。窗口模式和影院模式下，聊天本来就在播放器旁边。这个 Chrome 版本同样能在 Opera 里运行；Firefox 在 addons.mozilla.org 上有自己的版本。

■ 键盘操作与出问题时
每一项设置都为屏幕阅读器加了标签，滑块和选择器都能用方向键操作；只有调整大小和悬停才出现的那排控件需要鼠标。消息是 YouTube 自己的，屏幕阅读器读起来和侧边栏一样。每次改动代码都会跑一遍 WCAG 2.1 AA 自动检查，覆盖弹窗、那排控件和设置面板。
YouTube 经常改播放器，这个扩展从 2023 年一路跟到现在。万一真的坏了，设置面板里有状态显示、重启按钮，以及一键生成的诊断报告。报告里是扩展版本、你的浏览器，以及浮层在哪些地方挂上了、哪些地方没挂上——不含视频、频道或个人信息——而且只会进入你的剪贴板。
