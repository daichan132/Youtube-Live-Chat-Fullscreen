YouTube 실시간 스트리밍을 전체화면으로 보면, 채팅이 사라집니다.

이 확장 프로그램은 사라진 채팅을 영상 위로 다시 불러옵니다. 전체화면 그대로 메시지를 읽고, 채팅을 보내고, 실시간 스트리밍이라면 Super Chat까지 보낼 수 있습니다. 켜고 끄는 것은 재생 컨트롤 바에 늘어나는 버튼 하나. 무료이고, 웹페이지 중에서 움직이는 곳은 YouTube 안뿐입니다.

■ 주요 기능
- 원하는 위치와 크기: 드래그로 옮기고, 네 변과 모서리에서 크기를 조절합니다. 위치도 크기도 플레이어를 기준으로 기억하므로, 노트북에서 맞춘 배치가 32인치 화면에서도 그대로 맞습니다.
- 멀리서도 읽히는 글자: '글꼴 크기'는 10~40px, 기본값은 13px입니다. 상한인 40px은 평소 채팅 글자의 약 3배입니다. '글자색'과 '멤버 이름 색상'을 따로 정할 수 있고, 글꼴은 50종입니다.
- 영상에 묻히지 않는 배경: 처음에는 비치지 않는 흰색 패널입니다. '배경색'에서 색과 투명도를 한 번에 고르고, 0~20px의 '블러'를 더할 수 있습니다. 블러는 동작이 무거워지기 가장 쉬운 설정이라, 오래된 PC에서는 0으로 두는 편이 좋습니다.
- 사라지지 않는 채팅: '조작하지 않을 때도 표시'는 처음부터 켜져 있어, 재생 컨트롤이 사라져도 채팅은 화면에 남습니다. 이 설정이 켜져 있을 때 고를 수 있는 '채팅만 표시'를 쓰면 헤더와 입력창이 접히고, 커서를 올리면 원래대로 돌아옵니다.
- 이름 숨기기와 간격: 일반 메시지는 '사용자 이름 표시'와 '사용자 아이콘 표시'를 각각 끌 수 있습니다(유료 메시지의 이름과 아이콘은 그대로 남습니다). 메시지 사이 '간격'은 0~40px에서 조절합니다.
- 프리셋: 기본 제공 7종, 각각 클릭 한 번으로 적용됩니다. 지금 설정을 저장해 자신의 프리셋으로 늘릴 수도 있습니다.
- 키보드와 접근성: 슬라이더도 색상 선택도 방향키로 움직이고, 모든 컨트롤에는 스크린 리더용 이름이 붙어 있습니다. 마우스가 필요한 것은 컨트롤 줄을 불러올 때, '채팅만 표시'가 접어 둔 부분을 다시 꺼낼 때, 크기를 조절할 때뿐입니다. WCAG 2.1 AA 자동 검사는 팝업과 컨트롤 줄과 설정 패널을 대상으로, 코드를 바꿀 때마다 실행합니다.

■ 흉내 낸 채팅이 아니라, YouTube 자체의 채팅
영상 위에 겹치는 것은 사이드바에 나오는 것과 같은 YouTube 자체의 실시간 채팅입니다. 새로 만든 화면이 아니므로 멤버 배지도, 이모티콘도, 스티커도, 멤버 전용 채팅도 그대로 작동합니다. 채팅을 보낼 때는 YouTube의 입력창을, Super Chat은 YouTube의 구매 패널을 그대로 씁니다. 결제는 YouTube 쪽에서 이루어지고, 이 확장 프로그램으로 가는 돈은 없습니다. 이 패널 안에서 바꾸는 것은 멤버십 항목 하나뿐이고, 누르면 채널 가입 페이지가 새 탭에서 열립니다. 그 밖에 바꾸는 것은 기본적으로 색과 글자 크기, 간격 같은 겉모습입니다.

■ 요금과 개인정보
무료입니다. 계정 등록도, 유료 요금제도 없습니다.
권한은 activeTab과 storage 두 가지뿐이고, 웹페이지 중에서 실행되는 곳은 www.youtube.com뿐입니다. Chrome 설치 안내에 나오는 데이터 관련 문구가 뜻하는 것은 그것이 전부입니다. 백그라운드에서 계속 도는 구조는 없어서, YouTube 탭이 없으면 움직이는 것은 툴바 팝업뿐이고, 그것도 열려 있는 동안뿐입니다.
분석 도구도 추적도 없습니다. 읽은 메시지도 입력한 글자도 모으지 않고, 저장하지 않고, 어디로도 보내지 않습니다. 개발자에게 가는 데이터도 없습니다. 설정은 이 브라우저 안에만 남습니다. 코드는 모두 확장 프로그램 안에 들어 있고, 밖에서 받아오는 것은 글꼴뿐입니다. 기본 글꼴이 아닌 것을 고르면 Google Fonts에서 받아옵니다. 소스 코드는 GPL-3.0으로 GitHub에 공개되어 있습니다.

■ 시작하기
1. 설치한 뒤, 실시간 스트리밍이나 채팅 다시보기가 남아 있는 지난 방송을 엽니다.
2. 플레이어를 전체화면으로 만듭니다. 채팅은 이미 영상 위에 있습니다.
3. 컨트롤 바의 말풍선 버튼으로 켜고 끄고, 채팅에 커서를 올리면 나오는 설정 버튼으로 겉모습을 바꿉니다.

■ 실행 환경과 표시 언어
데스크톱 전용이며, 채팅이 있는 시청 페이지를 전체화면으로 볼 때만 나타납니다. 이 스토어의 Chrome용은 Opera에서도 쓸 수 있고, Firefox용은 addons.mozilla.org에 있습니다. 표시 언어는 브라우저와 따로 고를 수 있으며, 선택지는 55개, 언어로는 49개입니다.
