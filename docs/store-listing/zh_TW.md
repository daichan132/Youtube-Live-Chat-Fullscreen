YouTube 直播一進全螢幕，聊天室就不見了。

這個擴充功能把消失的聊天室重新放回影片上。維持全螢幕就能讀訊息、發言，直播時還能送 Super Chat。開關是播放控制列上多出來的一顆按鈕。免費，而且網頁裡只在 YouTube 中運作。

■ 主要功能
- 位置和大小自己決定：拖曳就能移動，四邊四角都能調整大小。位置和大小都以播放器為基準記住，筆電上調好的版面，換到 32 吋螢幕也合用。
- 離遠也看得清的文字：「字型大小」為 10～40px，預設 13px。上限的 40px 約為平常聊天文字的三倍。「字型顏色」和「會員名稱顏色」可以分開設定，字型有 50 種。
- 不被畫面蓋過的背景：一開始是不透明的白色面板。「背景顏色」裡顏色和透明度一起選，還能加上 0～20px 的「模糊效果」。模糊效果是最容易影響流暢度的設定，舊電腦上建議維持 0。
- 不會消失的聊天室：「閒置時顯示聊天室」預設開啟，播放控制列隱藏之後，訊息仍然留在畫面上。開著它才能選的「僅顯示聊天室」會收起標題列和輸入框，只留下訊息，把游標移上去就恢復。
- 隱藏名稱與間距：一般訊息可以分別關掉「顯示使用者名稱」和「顯示使用者頭像」（付費訊息的名稱和頭像仍然保留）。訊息之間的「間距」可在 0～40px 之間調整。
- 預設方案：內建七種，各點一下即可套用，也能把目前的設定存成自己的預設方案。
- 鍵盤與無障礙：滑桿和色彩選擇器都能用方向鍵調整，每個控制項都帶有螢幕閱讀器用的名稱。需要滑鼠的只有喚出控制列和調整大小兩處。每次改動程式碼，都會跑一次 WCAG 2.1 AA 自動檢查。

■ 不是仿製的聊天室，而是 YouTube 自己的聊天室
蓋在影片上的，就是側邊欄裡那個 YouTube 自己的即時聊天室。它不是重做的介面，所以會員徽章、表情符號、貼圖、會員專屬聊天都照常可用。發言用的是 YouTube 自己的輸入框，Super Chat 用的是 YouTube 自己的購買面板，付款在 YouTube 那一側完成，錢不會經過這個擴充功能。這個面板裡被改動的只有會員這一項，按下去會在新分頁開啟頻道的加入頁面。除此之外改動的，基本上是顏色、字級、間距這類外觀。

■ 費用與隱私
免費。不必註冊帳號，也沒有付費方案。
權限只有 activeTab 和 storage 兩項，網頁當中會運作的只有 www.youtube.com。Chrome 安裝提示裡關於資料的那句話，指的就是這些。沒有在背景常駐的部分，沒開 YouTube 分頁時，會動的只有工具列彈出視窗，而且僅限開著的那段時間。
沒有分析工具，也沒有追蹤。讀到的訊息和輸入的文字，都不收集、不保存、不外傳，開發者這邊也收不到資料。設定只留在這個瀏覽器裡。程式碼全部隨擴充功能一起提供，需要從外部取得的只有字型：選了預設以外的字型，才會從 Google Fonts 下載。原始碼以 GPL-3.0 在 GitHub 上公開。

■ 開始使用
1. 裝好之後，打開一場直播，或是打開保留了聊天重播的封存影片。
2. 把播放器切到全螢幕。聊天室已經在影片上了。
3. 控制列裡的對話框按鈕負責開關，設定按鈕負責調整外觀。

■ 運作環境與顯示語言
僅限桌機，只在有聊天室的觀看頁面進入全螢幕時出現。本商店的 Chrome 版同樣可以在 Opera 上使用，Firefox 版在 addons.mozilla.org。顯示語言可以和瀏覽器分開選，選項共 55 個，涵蓋 49 種語言。
