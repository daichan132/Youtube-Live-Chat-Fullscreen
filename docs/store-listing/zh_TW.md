YouTube 全螢幕播放時，也能看直播聊天室、傳送訊息。
YouTube 直播全螢幕聊天室是免費的 Chrome 擴充功能，將聊天室疊在影片上。不用離開全螢幕，就能一邊看直播，一邊參與討論。

直播與聊天室重播
看遊戲實況、VTuber 或現場活動時，也能看到觀眾的即時反應。提供聊天室重播的直播存檔，可以配著影片重溫當時的對話。

調整適合你的聊天室
- 透明背景：調整透明度和模糊效果，讓聊天室後方的影片也看得見。
- 位置與大小：拖曳聊天室避開重要畫面，並調整寬度與高度。
- 文字顯示：選擇字型、字級、文字顏色、背景顏色與訊息間距。
- 樣式預設：選用內建樣式，或儲存自己的外觀設定。
- 簡潔顯示：隱藏一般訊息的使用者名稱和頭像，或在未操作時收合輸入框。

直接使用 YouTube 聊天室
聊天室保留 YouTube 原有的表情符號、會員徽章和輸入框。直播時傳送訊息需要登入。支援的直播也可使用 Super Chat；能否發言及使用付費功能，依平台的使用條件和頻道設定而定。直播存檔呈現的是當時對話的重播，並非新的即時討論。

使用方式
1. 安裝擴充功能，開啟直播或有聊天室重播的直播存檔。
2. 按下影片播放器的全螢幕按鈕。
3. 將游標移到聊天室上，即可移動、調整大小或開啟設定。
使用播放器控制列中的聊天室按鈕，即可顯示或隱藏聊天室。如果先前關閉了功能，請在工具列的彈出視窗中開啟全螢幕聊天。

免費且開源
不需要為擴充功能另外註冊帳號或訂閱。原始碼以 GPL-3.0 授權條款在 GitHub 公開。影片平台提供的付費功能仍須另外付費。

隱私與權限
設定透過 storage 權限儲存在目前的瀏覽器中。擴充功能僅在 www.youtube.com 網頁上執行，不進行分析或追蹤，也不會把聊天內容或觀看記錄傳給開發者。原有聊天室會連線至 YouTube 服務；選用字型則從 Google Fonts 載入。

支援環境
適用於電腦版 Chrome，可用於有直播聊天室或可用聊天室重播的影片。沒有聊天室的影片不會顯示面板。Opera 等其他 Chromium 瀏覽器的相容情況可能因環境而異；Firefox 版可在 addons.mozilla.org 另外取得。設定支援鍵盤操作，並提供 55 種介面語言選項。
