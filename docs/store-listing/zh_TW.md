在 YouTube 直播切到全螢幕，聊天室就不見了。

這個擴充功能把它放回影片上方，讓你不必離開全螢幕，就能讀完每一則訊息、回覆，並在直播中發送 Super Chat 超級留言。面板一開始是不透明的白底黑字，顏色、透明度和字級都可以自己改。

不必縮小播放器，不必切到劇院模式，也不必把聊天室彈成小視窗放到第二螢幕——切到全螢幕，對話就在那裡，控制列上多出的一個按鈕負責開關。免費、開放原始碼，僅限桌機瀏覽器。

■ 不是仿製的聊天室，而是 YouTube 自己的聊天室，搬到影片上
疊在影片上的，就是側邊欄裡那個 YouTube 自己的即時聊天室。會員徽章、表情符號、貼圖、輸入框，以及 Super Chat 和 Super Sticker 的購買面板，全都是 YouTube 本身的畫面。發言會經過那個輸入框，所以照舊需要登入。往回捲動看舊訊息、會員專屬聊天室，表現都和播放器旁邊一樣。這個擴充功能不會重新產生訊息，改動的主要是外觀：顏色、大小和間距。

■ 用大螢幕看一場演唱會
把字級拉到 40px，把面板放到畫面一角。「閒置時顯示聊天室」預設就是開著的，所以播放控制列淡出之後，訊息也會一直留在那裡。

■ 在第二螢幕上掛著遊戲直播
開啟「僅顯示聊天室」，標題列和輸入框會收起來，只剩一欄乾淨的訊息；把滑鼠移上去，它們隨時都能回來。只有「閒置時顯示聊天室」是開著的，才能在設定面板裡找到它。再把面板拉成貼著螢幕一側的細長條，加一點模糊：明亮的遊戲畫面上也讀得清楚，又不擋視線。

■ 深夜補看存檔影片
打開一場還留著聊天回放的過往直播，切到全螢幕，聊天室就帶著你調好的面板和樣式回來了。拖動進度或改變速度，聊天室都會跟上，和側邊欄一樣——留言還是那些留言，這個擴充功能不加、也不藏。

■ 每種直播都有合適的樣子
內建七套預設方案。選「大字」——幾乎不透明的白色面板配 18px 黑字，不顯示使用者名稱和頭像——靠在沙發上也讀得清楚。也可以把自己的一套存起來，隨時改名、排序或刪除。

■ 可以調整的地方
位置：把面板拖到播放器上的任何地方。滑鼠移到面板上，正下方靠右會出現一排控制項——設定按鈕和拖曳把手（靠近螢幕底部時，它會上移到面板上）。這排控制項顯示著的時候，用 Tab 鍵移到把手上，方向鍵就能每次移動 10px。面板從一角開始，當字幕、選單、片尾畫面或控制列開始遮住它時，它會往被遮得最少的那一角移動一次。你自己放好之後，它就不再移動了。
大小：一開始約為播放器寬度的三分之一、高度的一半多一點；拖動任一邊或任一角，就能把它變成細長條或直立的一欄。位置和大小都依播放器換算，所以在筆電上調好的版面，換到 32 吋螢幕也合適。
背景：顏色和不透明度在同一個「背景顏色」選擇器裡，另有 0–20px 的「模糊效果」，讓面板在雜亂畫面上像霧面玻璃。模糊從 0 開始——這是唯一可能拖慢老機器的設定，老機器上建議維持 0。
文字：「字型大小」從 10px 到 40px，預設 13px——40px 大約是一般聊天文字的三倍。改變面板大小不會改動你選的字級。可以設定「字型顏色」，以及另外一個「會員名稱顏色」，還有 50 種「字型」（含日文字型），選了就立刻套用。
間距：訊息之間的「間距」為 0–40px，另有「顯示 Super Chat 欄」開關，以及針對一般訊息的「顯示使用者名稱」和「顯示使用者頭像」開關（付費訊息保留名稱和頭像）。
顯示：可以讓面板在你不動時也留著，也可以讓它在滑鼠和鍵盤安靜一秒後淡出，你一動它就回來。
復原：設定面板開著時，Cmd/Ctrl+Z 可逐步復原外觀變更，Shift+Cmd/Ctrl+Z 重做，最多 50 步——不含位置和大小。
主題：擴充功能自己的畫面可在工具列彈出視窗裡選「淺色」「深色」或「自動」。
語言：顯示語言也在同一個彈出視窗裡，與瀏覽器語言無關——涵蓋 49 種語言的 55 個選項，英語、西班牙語、葡萄牙語和中文分地區版本，阿拉伯語、希伯來語和波斯語支援由右至左的排版。

■ 按一下就回到平常的 YouTube
按下 YouTube 自己的聊天按鈕，覆蓋層就會關掉，頁面回到原樣；播放器上的按鈕和工具列圖示都能再把它打開。面板內的點擊和捲動只留在聊天室裡，不會誤按暫停或拖動進度；面板之外，播放器一切照舊。

■ 費用與收集的資料
免費——不需要帳號，也沒有付費方案。
兩項權限：activeTab 和 storage。程式碼只在一個網站上執行，www.youtube.com——Chrome 安裝提示裡說的讀取和變更資料，指的就是這一個網站。也沒有常駐背景的部分：沒有開著 YouTube 分頁時，只有正開著的工具列彈出視窗在運作。所有程式碼都隨擴充功能一起打包，唯一會從網路上取的是字型。預設字型什麼都不會載入；換成其他字型，或切到用了其他字型的預設方案，才會從 Google Fonts 取。
沒有分析、沒有追蹤，也沒有任何東西送給開發者：你讀到的和輸入的內容，不會被收集、保存或傳送到任何地方。Super Chat 的付款走的是 YouTube 的購買面板，而不是這個擴充功能；擴充功能在那個面板裡改動的只有「會員」一項，按下後會在新分頁開啟頻道的加入頁面。設定只留在這台電腦的這個瀏覽器裡，不會透過 Google 帳戶同步；彈出視窗可以把設定匯出成檔案，在別處匯入。
以 GPL-3.0 開放原始碼：完整程式碼公開在 GitHub 上，這裡寫的每一句你都可以自己去核對。

■ 怎麼開始
1. 安裝後，打開一場直播，或一個有聊天回放的存檔影片。
2. 把播放器切到全螢幕。
3. 聊天室就回到影片上方了——不用開啟任何開關。
4. 控制列右下角新增的對話框按鈕負責開關，面板上的設定按鈕負責調整外觀。兩者都會帶到下一場直播。

面板只在全螢幕、而且是有聊天室的觀看頁面時出現——一般影片，或聊天回放已經沒有了的直播，按鈕根本不會出現。視窗模式和劇院模式下，聊天室本來就在播放器旁邊。這個 Chrome 版本同樣能在 Opera 裡執行；Firefox 在 addons.mozilla.org 上有自己的版本。

■ 鍵盤操作與出問題時
每一項設定都為螢幕閱讀器加了標籤，滑桿和選擇器都能用方向鍵操作；只有調整大小和滑鼠移上去才出現的那排控制項需要滑鼠。訊息是 YouTube 自己的，螢幕閱讀器讀起來和側邊欄一樣。每次改動程式碼都會跑一遍 WCAG 2.1 AA 自動檢查，涵蓋彈出視窗、那排控制項和設定面板。
YouTube 經常改播放器，這個擴充功能從 2023 年一路跟到現在。萬一真的壞了，設定面板裡有狀態顯示、重新啟動按鈕，以及一鍵產生的診斷報告。報告裡是擴充功能版本、你的瀏覽器，以及覆蓋層在哪些地方掛上了、哪些地方沒掛上——不含影片、頻道或個人資訊——而且只會進到你的剪貼簿。
