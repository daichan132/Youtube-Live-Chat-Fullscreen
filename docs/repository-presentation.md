## Measurement

Do not add a new analytics SDK. Record GitHub Traffic once a week on the same weekday:

- New stars
- Unique visitors
- Stars divided by unique visitors
- Referring sites
- Store rating and recent review sentiment

Evaluate repository conversion before increasing external promotion. If visitors rise without stars, improve the first-view explanation. If conversion is healthy but visitors stay flat, expand technical articles and community distribution.
