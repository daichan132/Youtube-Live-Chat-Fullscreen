# Chrome Web Store image concepts

Target: 1280 × 800 px (16:10), full bleed, square corners.

These are independent visual directions for selection. They use fictional stream
content and avoid third-party logos, real creators, ratings, awards, or unsupported
performance claims.

1. **消えたチャットが帰ってくる** — fullscreen without chat transforms into fullscreen with the overlay.
2. **配信に溶け込む透明チャット** — a translucent violet chat layer preserves the performer.
3. **ドラッグしてベストポジション** — restrained motion cues show the overlay moving to the ideal spot.
4. **指先ひとつでリサイズ** — corner handles expand a compact chat into a comfortable reading area.
5. **右下スイッチで即表示** — a single illuminated toggle reveals the chat overlay.
6. **映像主役のミニマル配置** — a narrow edge-aligned chat leaves nearly all video unobstructed.
7. **コメントが流れる特等席** — the viewer feels seated inside a concert with reactions close at hand.
8. **ゲーム画面を避ける配置** — chat sits outside the HUD and central action zone.
9. **縦長チャットの定番形** — a tall, clean sidebar overlay emphasizes familiar readability.
10. **横長コメントバー** — a shallow bottom overlay works like an audience reaction ribbon.
11. **四隅から選べる自由** — four faint placement possibilities surround one active chat.
12. **中央を空けるコの字構図** — chat and controls frame the video without covering its subject.
13. **視線移動を最小に** — performer and chat are compositionally close but never overlap.
14. **大画面テレビでも読みやすい** — a living-room viewing scene emphasizes large, clear messages.
15. **ノートPCでも広々** — compact fullscreen viewing retains a slim, usable overlay.
