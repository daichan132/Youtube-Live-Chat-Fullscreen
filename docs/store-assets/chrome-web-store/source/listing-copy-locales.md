## Review scope

Every manuscript received a writing pass and a separate review for feature meaning, conditions and plain language. The Japanese yomiyasu principles guide meaning preservation and restrained wording; Japanese grammar rules and lint scores do not certify other languages. Native-speaker proofreading has not been performed.

All nine topics remain in every locale: the viewing benefit, live/replay use cases, five customization controls, participation conditions, setup, price, privacy, compatibility and support links. Search terms use local expressions for fullscreen video, live chat, overlays and chat replay where space permits; the summaries retain ordinary-message posting and Super Chat.

Five feature bullets and three setup steps remain because they describe parallel controls and an actual sequence. Japanese lint candidates about list density and repeated polite endings were reviewed in context rather than removed to maximize a score.

The descriptions are prepared repository copy. The public store listing has not been changed.
